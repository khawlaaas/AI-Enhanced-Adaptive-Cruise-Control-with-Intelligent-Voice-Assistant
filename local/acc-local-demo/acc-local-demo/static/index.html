An adaptive cruise control system that reads eight independent perception signals off the road ahead, feeds them into one priority-ordered decision engine, and hands the reasoning to a multilingual voice assistant that never touches the vehicle without asking first.

Perception layer

8 independent models → one road-state snapshot
01 · KERAS CNN
Road-type classifier
autoroute / urbaine / rurale, trained on the A2D2 mirror + extra rural data.
02 · ROBOFLOW
Off-road / surface
Overrides road-type to "off-road" when the surface isn't paved.
03 · ROBOFLOW
Road damage
Potholes / cracks → applies a flat speed reduction.
04 · YOLOv11
Traffic signs
Stop, red light, posted speed limits.
05 · YOLO (custom)
Speed bumps
Own-trained detector; only "Speed-Bump" triggers a cap.
06 · YOLO (custom)
Pedestrians & crosswalks
Bbox size/position heuristic separates "close" from "far".
07 · TFLITE
Weather classifier
clear / adverse, only trusted above a 0.70 confidence bar.
08 · YOLOv8n
Vehicle distance
COCO-pretrained; box height + position stand in for real distance.
